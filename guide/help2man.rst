===================
help2man 利用ガイド
===================

LDP man-pages の翻訳は、help2man というツールを使います。
ここでは、help2man について使い方などを解説します。

help2man とは
=============

help2man とは、 GNU プロジェクトの一部で、プログラムに備わっている
ヘルプ出力 (--help オプションを付けて表示されるもの) を、man 形式
(example.1 のようなもの)に変換するプログラムです。
マニュアルの形式はあらかじめ決まっていて、その形になるようにヘルプ
出力を変換します。
また、英語だけではなく、一応多言語にも対応しています。
help2man は多くのディストリビューションで標準で入っている事が多いです。

help2man の大まかな動作
=======================

help2man の大まかな動作は以下のようになります。

1. locale、プログラムの出自および対象となるプログラムを指定して help2man を起動する。
2. 追加ファイルが有ればそれを読み込む。
3. 対象となるプログラムを --help オプションを付けて起動し、結果を得る。
4. 結果を解析し、標準的なマニュアル形式に変換し、出力する。

help2man の内部動作
-------------------

help2man は内部でおおよそ下記のことを行ないます。

1. 追加ファイルの読み込み
   help2man は最初に追加ファイルを読みます。追加ファイルはセクション名と本文から成り立っています。形式は

.. code-block:: console

	[section名]
	セクションの内容
	....
	[section名]
	セクションの内容
	...

というようになっています。セクション名は英語でも日本語でも構いません。セクション名をキーとして、help2man はそのセクションの内容を保持します。

2. プログラム出力の読み込み

help2man は、--help オプションを付けたプログラムからの出力を一気に読み込みます。

3. helpメッセージの解析

helpメッセージを解析します。helpメッセージはあらかじめ決まったフォーマットになっています。メッセージの中からセクションのキーワード、たとえば英語での DESCRIPTION とか EXAMPLES とかを拾い出し、セクションごとのデータ領域(ハッシュ領域)に格納します。

4. 定型文の出力

help2man の中には、定型文を持っている所があります。具体的には、GNU の web サイトにあるコマンド説明へのリンク、翻訳についての問い合わせ先です。それを出力に追加します。

JM project での利用
===================

JM project では、help2man を使って、GNU coreutils のマニュアルを生成しています。
具体的には、GNU_coreutils ディレクトリ中の help2man.jp ディレクトリ内にある Makefile で作成を行っています。
このディレクトリには、各コマンドに対する追加ファイル(arch ならば arch.x) が含まれています。このファイルには、マニュアルを作成する時に必要な、翻訳済みの[名前],[説明],[関連項目] セクションが含まれています。--help での出力結果では、[名前] や [関連項目] は含まれていないので、手動で補足しています。

Ver 1.49.3 の help2man における問題点
=====================================

公式リリースの help2man 最新バージョンは 1.49.3 です。しかしこのバージョンはいくつも問題点があります。

1. helpメッセージに埋め込まれているハイパーリンクに未対応
   最近(どこからかは不明)のcoreutils では、ヘルプメッセージの一部に URLが埋め込まれるようになりました。しかし、help2man はこれを処理できません。そのため、不正なエスケープシーケンス等が出力されてしまいます。
2. 翻訳されたセクション名に未対応
   ソースを見る限り、セクション名が翻訳されているとそのことを認識できません。一応 gettext 関数は使っていますが、処理に抜けがあり、翻訳されたセクション名があると誤動作します。これは日本語のような多バイト言語だけではなく、ISO-8859 のような1バイト圏言語でも同様です。
3. 埋め込まれているメッセージが古い
   最近(どこからかは不明)の coreutils に含まれるコマンドでは、末尾に表示されるメッセージが、help2man 埋め込みのメッセージとは異なります。
